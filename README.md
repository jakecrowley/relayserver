# relayserver

A fork of [OpenBubbles/relayserver](https://github.com/OpenBubbles/relayserver):
a Rust relay server for iOS, packaged as the jailbreak LaunchDaemon package
`dev.copper.relayserver`.

## Install via Sileo

1. Add the repository URL `https://jakecrowley.github.io/relayserver/` as a
   source in Sileo (Sources → Add).
2. Install `dev.copper.relayserver`.

Releases are built and published automatically by CI on version tags.
